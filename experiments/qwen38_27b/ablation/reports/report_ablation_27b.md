**结论 A（指令范式）**：同样只用 5k 数据，8B 从 schema 换成 simple 掉 **31.5%**（91.9% → 60.4%），27B 只掉 **2.6%**（92.0% → 89.5%）。即 **8B 在训练期高度依赖 schema 指令，27B 几乎不依赖** —— 这是换基座带来的、8B 上观察不到的鲁棒性增益。

- **数据量（schema）**：27B 从 5k 加到 35k（7× 数据）只涨 **+1.4%**，8B 同区间为 +1.5%（差 0.1%）—— 数据量曲线在两个基座上几乎重合，**说明这条曲线由数据/标注口径决定，与基座规模无关**。

- **为什么不再补 20k / simple-35k**：27B 的 `schema-5k`(92.0%) 与 `schema-35k`(93.4%) 两个端点都与 8B 同格（91.9% / 93.4%）相差 ≤0.1pt，8B 已知的中间点 20k=92.9% 也落在同一条线上，补跑只会在一条已被两个基座验证的曲线上再取一个点；`simple-35k` 同理 —— 8B 加到 7 倍数据也只从 60.4% 升到 75.3%，始终够不到 schema 分支，而 27B 在 5k 就已经 89.5%，方向已经相反地确定了。
